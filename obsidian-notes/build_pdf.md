# build_pdf

> `memoire/build_pdf.py`

## Rôle

Convertit un Markdown de soutenance en PDF via markdown → HTML → xhtml2pdf. Nettoie les emoji non rendus par le moteur PDF.

_Aucune (module feuille)._

- `os`
- `sys`
- `markdown`
- `xhtml2pdf`
- `reportlab`
