# Durée des interventions

## Temps estimé par prestation

| Prestation | Durée estimée |
|---|---|
| Reprogrammation Stage 1 | 1h30 à 2h |
| Conversion E85 | 1h30 |
| Suppression FAP | 1h à 1h30 |
| Suppression EGR | 1h |
| Suppression AdBlue | 1h à 1h30 |
| Diagnostic simple | 20 min |
| Diagnostic approfondi | 35 min |
| Recherche de panne | 1h |

## Informations pratiques
- La plupart des prestations sont réalisées **dans la journée**
- Vous récupérez votre véhicule **le jour même** dans la grande majorité des cas
- Pour les cas complexes (Stage 2+, cumul de prestations), compter une demi-journée à une journée complète
- Nous vous communiquons un créneau précis lors de la prise de rendez-vous
